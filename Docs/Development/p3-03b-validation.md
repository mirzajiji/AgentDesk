# P3-03b — Interactive Jira OAuth lifecycle

Status: lifecycle implementation ready for review; live acceptance remains incomplete. The [optional exchange service](../../Services/JiraOAuthBroker/README.md) is implemented locally, with confidential code/refresh exchange, proof-protected claims, expiry, admission limits and graceful shutdown. The public native API supports scoped sign-in, refresh, logout and disposal. Native controls remain P3-05.

Public OAuth registration, the publisher secret channel and an HTTPS deployment are not configured. No live browser consent or account exchange has been performed. Local socket/transport fixtures do not establish that external registration works. This task stays in progress until that acceptance is available; the implementation can be committed without claiming the integration is ready for users.

Final implementation checkpoint: 62 plugin tests pass through host SwiftPM, native Mac and iPhone 16 Pro/iOS 26.0; 21 broker tests pass through host SwiftPM. The service process smoke test covers loopback startup/request/shutdown and safe configuration failures. See the chronological records below for exact commands and result paths.
